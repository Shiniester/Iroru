# ADR 0005: 视频使用 Flutter 页面并接入源站账号

视频功能采用 Flutter 页面，沿用 KikoFlu 的界面风格。
应用标签栏按音声、漫画、视频、设置排列。
横屏沿用侧栏导航。
视频页复用现有页头、抽屉和主题。
源站功能变化需要由 KikoFlu 跟进适配。

视频播放器的界面、功能与后台播放规则以 [ADR 0006](0006-piliplus-video-player-parity.md) 为准。

## 功能范围

[MissAV](https://missav.ai/) 是首个视频源。
首版包含源站账号，不包含会员能力。
首版覆盖 Android、iOS、Windows、macOS 和 Linux。
原生功能暂不可用时，提供“在源站打开”入口。
页面注明暂未接入的功能。

首版源站功能范围：

- 目录与搜索：首页、最新更新、新作、字幕专区、榜单、演员、分类、厂商及专题入口。
- 详情与播放：视频信息、相关推荐和原生播放控制。
- 账号：登录、退出、注册、密码管理、视频收藏、演员收藏、播放列表及观看历史。

## 播放规则

播放器位于视频详情页顶部，并提供全屏切换。
视频信息和相关推荐位于播放器下方。
播放控制包括播放/暂停、进度、倍速、独立音量和全屏。
清晰度和字幕选项以源站播放流提供的内容为准。
离开播放页、退到后台或锁屏时，暂停视频并保留进度。
返回播放页后，手动继续播放。
全屏切换保留当前播放状态和进度。

音声与视频允许同时播放。
音声和视频分别提供应用内音量控制。
调节一方的应用内音量不改变另一方的音量。
系统音量仍作用于设备总输出。

## 资料归属

| 资料 | 保存位置 | 未登录时的行为 |
| --- | --- | --- |
| 视频源收藏、演员收藏 | 视频源账号 | 提示登录，不保存本地收藏 |
| 播放列表 | 视频源账号 | 提示登录 |
| 观看历史列表 | 视频源账号 | 不显示 |
| 视频续播进度 | 本机 | 可用，重启后仍可恢复 |
| 视频下载 | 本机 | 源站允许访问时可下载；已完成的下载可离线播放 |

退出视频源账号后，保留本机下载和续播进度。

## 离线下载

首版提供视频离线下载。
离线下载供 KikoFlu 内播放。
下载任务提供进度、暂停、继续、失败重试和删除操作。
允许系统在后台或锁屏时暂停下载。
保留下载任务和已下载内容，返回或重启后可继续。
重启后，未完成任务恢复为暂停状态，可手动继续。

## 实施与验收

功能说明和检查结果见[视频接入](../video-integration.md)。

MissAV 的验证提示、首播与媒体转发的后续决策见 [ADR 0013](0013-missav-verification-and-playback-recovery.md)。

2026-11-15 修订：MissAV 访问改为原生优先。
应用先使用保存的 Cookie 和 User-Agent 请求原生页面、账号 API 和媒体地址。
原生请求遇到 Cloudflare 验证页或 HTTP 403 时，恢复浏览器会话或显示“验证访问”。
没有保存会话时，先尝试建立隐藏浏览器会话，仍失败才显示“验证访问”。
网页验证保留为失败回退，不作为默认访问方式。

以下 2026-11-16 修订记录当时的探测方案；内容线路已由文末修订取代。
2026-11-16 修订：未选择线路时，MissAV 首次在线访问先并发探测候选官方备用域名和匿名镜像站。
官方备用域名优先于第三方镜像；有保存会话时，候选官方域名携带保存的 Cookie 和 User-Agent，第三方镜像不接收。
镜像站按测速结果选择；设置页列出全部域名，不可用线路不能选择。
视频设置提供测速、手动选择和恢复自动选择。
镜像站提供目录、搜索、详情和媒体页面，不需要网页验证。
镜像站列表、搜索接口和媒体改写见[MissAV 镜像访问](../development/missav-mirror-access.md)。
源站账号 Cookie 只发送给官方域名 `missav.ai`、`missav.ws` 和 `missav.live`。
所有候选域名均失败时，才请求 `missav.ai`；仍被验证时恢复浏览器会话或显示“验证访问”。

2026-11-16 修订：MissAV 账号登录不再打开网页登录页。
登录遇到视频源验证时，账号页保留表单并提示选择“验证访问”。
用户选择“验证访问”后打开验证窗口。验证通过后，用户在账号页重试登录。
手动验证步骤和登录后的浏览器处理以 2026-11-17 修订为准。
验证窗口只通过 Cloudflare，保存 Cookie 和 User-Agent 供后续账号请求。
验证浏览器固定使用 `missav.ai`；登录成功后关闭浏览器，并恢复所选账号线路。

2026-11-16 修订：原生账号登录和账号 API 使用当前官方线路。
官方线路候选为 `missav.ai`、`missav.ws` 和 `missav.live`。
账号登录默认按 `missav.live`、`missav.ws`、`missav.ai` 顺序尝试，账号页可选择线路。
第三方镜像只承载匿名内容，不接收账号 Cookie。
验证浏览器固定使用 `missav.ai`。登录后的账号线路以 2026-11-17 修订为准。

2026-11-17 修订：MissAV 登录遇到视频源验证时自动打开验证窗口。
如果源站确认网页已登录，应用直接接续网页会话。
如果网页只通过了视频源验证，应用用本次输入的邮箱和密码重试一次。
用户取消或验证失败时，账号页保留表单、已填信息和“验证访问”按钮。
正常登录仍只提交邮箱和密码，不打开网页。
收藏、视频播放列表和视频观看历史使用账号线路。
通过验证浏览器登录后，应用保留浏览器会话供账号请求使用。
账号验证不等待媒体转发启动；媒体转发在验证后继续建立。
只完成视频源验证的用户仍可重试登录。
媒体转发尚未就绪时，播放会再次提供验证入口。
视频详情和视频播放列表封面仍按内容线路顺序加载。

2026-11-16 修订：内容线路改为缓存优先，官方线路最后回退。
内容页先使用上次成功的内容线路，再按实测顺序尝试镜像；全部镜像失败后才使用官方线路。
内容请求不预测速、不持久化页面，也不自动恢复浏览器；只有官方线路的验证错误显示验证入口。
内容线路与账号线路分离；详见 [ADR 0012](0012-missav-content-host-cache.md)。

原始验收阶段曾记录直接请求源站首页遇到浏览器验证。
该记录只说明当时的网络结果，不再作为默认传输方式的依据。
源站账号、视频播放和离线下载仍按实际网络完成验收。

验收覆盖以下行为：

- 目录、搜索和详情使用原生页面；暂未接入的功能可打开源站。
- 源站账号资料随账号切换，视频账号与音声、漫画账号独立。
- 音声与视频同时播放，分别调节音量；离页和后台暂停只影响视频。
- 续播进度跨重启恢复；下载可暂停、继续、重试和删除。
- 已完成的下载在断网时可播放。
- Android、iOS、Windows、macOS 和 Linux 分别验证播放与下载。
