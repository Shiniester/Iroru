# MissAV 内容线路缓存与官方线路回退

## Status

Accepted

## Context

MissAV 官方域名需要 Cloudflare 验证，第三方镜像站不需要。首次进入视频页和重启后重新选择线路会增加等待，并可能在探测失败时误触发验证入口。

## Decision

内容页先使用上次成功的内容线路，再按实测顺序尝试其余不需要 Cloudflare 的镜像。只有全部镜像失败后，才按 `missav.live`、`missav.ws`、`missav.ai` 尝试官方线路。

内容线路在真实页面请求失败或遇到 Cloudflare 时清除；手动选择的线路也只在遇到 Cloudflare 时清除。视频页直接加载第一页，不单独预测速，也不持久化页面内容。

账号登录和账号 API 使用独立的账号线路，仍是官方域名；账号页可选择线路。只有官方线路的验证错误显示验证入口，内容镜像的失败不得弹出网页验证，也不自动打开隐藏浏览器。

## Consequences

正常首次进入和重启只发一次页面请求。所有镜像失败时仍可能需要源站验证。账号状态在内容镜像上不可用，详情页跳过账号 API，不影响视频列表和播放。
